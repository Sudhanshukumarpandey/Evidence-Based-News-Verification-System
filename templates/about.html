About the Project

A look at the technology, dataset, and architectural design of this machine learning system.

Project Overview

The Fake News Detection System is a classical Natural Language Processing (NLP) and Machine Learning application designed to assess the authenticity of news headlines and articles. The primary objective is to differentiate between genuine news reporting (factual events) and fake news items (conspiracy, clickbait, false information).

Text Preprocessing Pipeline

Raw text data is unstructured and noisy. To train clean classical models, the input text goes through a strict sequence of cleaning operations:

  • Lowercase Conversion: Standardizes spelling differences (e.g. "Gov" and "gov").
  • URL & HTML Tag Removal: Clears out crawled web noise and links.
  • Number & Punctuation Removal: Substitutes numbers and punctuation characters with spaces to separate tokens clearly.
  • Stopwords Filtering: Removes common words (e.g. "he", "was", "the") that add no predictive signals.
  • Lemmatization: Reduces inflected forms to base dictionary words (e.g. "discovered" -> "discover", "countries" -> "country").

Model Architecture

We extract numerical features using a TF-IDF Vectorizer with an ngram_range=(1,2) and limit the vocabulary to the top 5000 features. We train and evaluate three classical algorithms:

  • Logistic Regression: A linear model that applies the Sigmoid function to map text features into probabilities ($0$ to $1$). Excellent for high-dimensional text datasets.
  • Multinomial Naive Bayes: A probabilistic classifier based on Bayes' Theorem, calculating the joint probability of words given a class. Highly efficient for text frequency analysis.
  • Linear Support Vector Machine (SVM): Finds the optimal hyperplane that separates the Real and Fake news classes with maximum margin. Known for superior performance on text boundaries.
